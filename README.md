# ✨ ديلي جنشن (Daily Genshin + Full Database & Build Calculator)

تطبيق ويب خفيف باللغة العربية لمتابعة مهام Genshin Impact اليومية والأسبوعية، عداد الحظ (Pity)، و**قاعدة بيانات وحاسبة تطوير شاملة لكل شخصيات وأسلحة وآرتيفاكتس اللعبة**.

## المميزات الجديدة
- **🧮 حاسبة الموارد والمتبقي (`بيلد وموارد`):**
  - اختيار أي شخصية وتحديد لفلها الحالي والمستهدف (`1 -> 90`) ومرحلة الـ Ascension (`A0 -> A6`).
  - تحديد لفل التالنت الثلاثة (`Normal / Skill / Burst` من `1 -> 10`) مع أزرار سريعة (`1/9/9`, `9/9/9`, `10/10/10`).
  - اختيار السلاح وتحديد لفله (`1 -> 90`) مع عرض **الأسلحة المقترحة للشخصية أولاً**.
  - إدخال الكميات الموجودة معاك في المخزون (تُحفظ تلقائياً في المتصفح) وحساب **المتبقي الفعلي** مع **التحويل التلقائي 3:1 (Crafting)**.
  - عرض أفضل الأسلحة وأطقم الـ Artifacts والـ Main/Substats المستهدفة لكل شخصية.
- **🤖 تحديث أوتوماتيك بالكامل via GitHub Actions:**
  - ملف `.github/workflows/sync-db.yml` يقوم بتشغيل `scripts/sync-database.mjs` تلقائياً لجلب بيانات كل الشخصيات والأسلحة والآرتيفاكتس من `genshin-db` وتحديث مجلد `data/` بدون أي تدخل يدوي.

## طريقة التفعيل في الريبو
1. ارفع الملفات الموجودة في هذا الأرشيف إلى الريبو `yusufaabozeed/genshin`.
2. من تبويب **Actions** في GitHub، شغّل الـ Workflow باسم **Sync Genshin Database** (أو سيعمل تلقائياً عند الرفع) ليملأ ملفات `data/` بكل شخصيات وأسلحة اللعبة دفعة واحدة.
